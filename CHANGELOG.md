# Changelog

## [1.0.1]

- **QR background color fixed** — Changing the background color in the UI now correctly affects the generated QR code (PNG and SVG). Previously only the foreground (dark modules) was customized; light modules were always drawn in white and covered the background. The generator now sets both dark and light module colors so the chosen background is applied to all non-data areas.
